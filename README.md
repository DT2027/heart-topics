# 真心话题库 · 500 题

> 输入题号，抽一道此刻刚好想聊的真心话。

**在线地址：** https://dt2027.github.io/heart-topics/

一个零依赖的静态网页：输入 1–500 之间的题号并点击「确定」，即刻输出对应题目；输入过的题号会按从小到大的顺序排列在输入框下方，随时点回重看。

## 功能

- **题号 → 题目**：输入题号回车或点击「确定」，立刻显示对应题目与层级标签。
- **历史提示**：浏览过的题号以彩色胶囊形式按升序排列在输入框下方，点击任一胶囊即可跳回那道题。
- **关掉再回来，记录还在**：已浏览题号有三层保障 —— `localStorage`、cookie（一年有效期）、以及**自动写进地址栏**（`?seen=88,231`）。退出链接、关掉标签页、换天再进入都能继续看到；某个标签页浏览过题目，其他标签页也会同步。
- **跨设备延续**：地址栏会自动带上已浏览题号；点「复制历史链接」也会生成带 `?seen=88,231` 的地址，在另一台设备或另一个浏览器打开该链接，已浏览题号会自动并入列表。
- **随机一题**：一键随机抽取一题。
- **上一题 / 下一题**：按序号连续浏览，方便一个接一个聊下去。
- **复制题目**：一键复制「第 N 题｜题目文本」。
- **链接直达**：`https://dt2027.github.io/heart-topics/#231` 可直接打开指定题目。

## 题目分层

500 道题按话题浓度分为五层，每层 100 道，**已均匀打散铺满 1–500 号位**：

| 层级 | 题数 | 聊多久 | 适合场景 |
| --- | --- | --- | --- |
| 破冰 | 100 | 3–5 分钟 | 初次见面、气氛冷场 |
| 进阶 | 100 | 5–8 分钟 | 熟一点之后，聊起相处与沟通 |
| 亲密 | 100 | 5–10 分钟 | 关系升温，聊信任与边界 |
| 自省 | 100 | 8–12 分钟 | 向内看，聊自我与选择 |
| 深度 | 100 | 10–15 分钟 | 深夜长谈，聊意义与人生 |

打散规则（由构建脚本自动保证，并在每次构建后输出统计报告）：

- 任意**连续 5 题**内必定出现全部 5 个层级；任意连续 10 题同样。
- 任意**连续 25 题**内，各层级数量恰好各 5 道，偏差为 0。
- 不会出现连续两道同层级。
- 重排使用固定随机种子 `20261112`，重复构建结果完全一致，可复现。

也就是说：随手按 1、2、3、4、5 浏览，永远一次就能覆盖从破冰到深度的全部五种浓度。

## 隐私与安全

- 所有题目都不询问收入、住址、单位、身份信息、病史、过往性经历等隐私内容。
- 话题以**偏好、感受、假设、观点**为主，允许对方选择跳过。
- 页面本身不收集、不上传任何数据；历史记录只存在你自己的浏览器里。
- 纯静态页面，无第三方脚本、无统计代码、无外部资源请求。

## 本地运行

直接双击 `index.html` 即可打开。若想用本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 目录结构

```
.
├── index.html              # 页面结构
├── styles.css              # 多巴胺配色与场景动画（蓝天 / 草坪 / 风筝 / 阳光）
├── app.js                  # 交互逻辑（查询、历史、随机、复制）
├── questions.js            # 题目数据（自动生成，勿手改）
├── QUESTIONS.md            # 全部 500 题的审查清单（按序号 + 层级索引）
├── data/batch-*.json       # 题目原始数据（分 5 批，每批 100 题）
├── scripts/build-questions.js  # 合并脚本：校验 + 生成 questions.js 与 QUESTIONS.md
└── package.json
```

## 修改题目

题目原始数据放在 `data/batch-1.json` ~ `data/batch-5.json`，改完后重新构建：

```bash
npm run build
```

构建脚本会自动校验并报告：题目总数是否为 500、序号 1–500 是否连续无缺失、是否存在重复文本、是否有超长或含英文单词的题目。校验不通过时脚本会直接报错退出。

> 如果修改了 `styles.css`、`app.js` 或 `questions.js`，请同步把 `index.html` 里这三个资源的 `?v=` 版本号往上加一位（如 `?v=3`），避免浏览器继续用旧缓存。

## 技术说明

- 纯 HTML / CSS / JavaScript，无框架、无构建依赖，双击即可运行。
- 背景场景全部由 CSS 与内联 SVG 绘制：渐变天空、呼吸感太阳、漂移云层、起伏草坪、飘动的风筝、飞鸟与小花。
- 响应式布局，手机端输入框与按钮纵向排列。
- 尊重 `prefers-reduced-motion`，系统开启减弱动效时自动停止动画。
